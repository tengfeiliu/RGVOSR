# 基于输出强化与结构化修复指令的 SR 融合实施方案

版本：v1.1（2026-09-08：明确第三、第四轮持续收益目标）  
适用项目：RGVOSR / RG-FLUX-SR  
方案性质：研究实施设计；尚未实现或验证本文新增模块。  
核心目标：在受控推理预算下提高真实 SR 质量、内容忠实度与失败案例表现。

## 1. 推荐路线与范围

采用以下顺序，每一阶段用画质证据决定是否继续：

P0 固定逐轮基线与评估协议 → P1 校准奖励 → P2 共享精修器的多轮状态训练（2→3→4 轮课程） → P3 冻结 VLM 的逐轮结构化修复 → P4 指令策略学习或多轮终局信用分配 → P5 按实际需求压缩部署。

核心目标是让当前第三、第四轮相对第二轮的退化得到改善，并争取第三轮优于第二轮、第四轮优于第三轮。两轮只是已有有效基线和最小调试起点，不是部署轮数上限。首轮放大，所有后续轮保持输出分辨率。每次完整图像生成是外层动作；不将 FM 内部采样 step 定义成 RL 动作。FM 训练仍会抽取噪声时间，这是训练变量，不是外层决策时序。

当前优先验证三个假设：

1. 奖励校准后，输出强化能够超过相同输入结构、相同训练预算的监督精修。
2. 将第二、第三轮输出作为训练状态，并学习适应当前残余问题，能够使第三、第四轮产生实际新增收益。
3. 冻结 VLM 的逐轮指令与后续终局回报，有助于改善多轮精修的定向性和协作性，而不是仅将最优结果继续停留在第二轮。

不要求每一张图、每一项指标都随轮数严格提高；对于已经恢复充分或信息不足的图像，应允许保持或停止。但“提前停在第二轮”只能证明减少退化，不能作为第三、第四轮能力提升的证据。主动生成的逐轮结果与停止/择优后的结果必须分开报告。

不把统一 Diffusion-AR、长文本推理、多轮自适应停止、MoE 重构、单步蒸馏一起作为首期依赖。上传研究计划提供研究参考，不自动变成本次的工程交付或论文承诺。

本文所有数据量、超参数、验收阈值均为建议起点，不是实测结果。GPU 型号、数量、可用专家标注预算尚未确定，因此以阶段产出和计算量核算安排执行，不承诺固定训练天数。

## 2. 系统与模型角色

令原始 LR 为 x，对齐 HR 为 h，首轮输出为 y1，最终输出为 y2，结构化指令为 d。

以下两轮公式用于说明最小单次更新单元，不限制实际迭代深度。无指令阶段：

\[
y_1=F_0(x;\epsilon_1),\qquad
y_2=G_\phi(x,y_1;\epsilon_2).
\]

引入冻结 VLM 后：

\[
d=H_\psi(x,y_1),\qquad
y_2=G_\phi(x,y_1,d;\epsilon_2).
\]

正式多轮执行采用共享精修器：

\[
d_k=H_\psi(x,y_k,k),\qquad
y_{k+1}=G_\phi(x,y_k,d_k,k+1;\epsilon_{k+1}),\quad k=1,\ldots,T-1.
\]

首期正式实验覆盖 T=2、3、4，不将四轮视为理论上限。先共享精修 LoRA，加入轻量轮次条件并重点使用当前图像/残余缺陷；只有证据显示共享参数冲突时才增加轮次专属小 adapter。每轮一个独立大模型不作为默认实现。

H 同时看原始 LR 与当前 SR；不能只根据原始 LR 推断当前剩余问题。H 不接收 HR。每轮重新诊断，缓存按当前图像更新。奖励模块与 H 分离，奖励主要看图像，不因指令或解释“写得好”而加分。

| 对象 | 作用 | 初期状态 |
|---|---|---|
| F0 | 首轮 SR 教师与基线 | 全程冻结 |
| Gφ | 第 2、3、4 轮共享精修执行器 | 训练 LoRA、必要条件 adapter 与轻量轮次条件 |
| G_old | 本批候选生成和 NFT 行为基准 | 批内冻结，按外层迭代刷新 |
| G_ref | 精修 SFT 完成时保存的参考模型 | 固定不刷新 |
| Hψ | 质量诊断与结构化指令提案 | P3 冻结；P4 视实验结果学习 |
| Rω | 质量、忠实度和局部风险评价 | 每次策略训练运行内固定版本 |
| 数据与评估模块 | 版本记录、候选缓存、专家标签和独立验收 | 独立于策略更新 |

基座 Transformer、VAE、文本编码器初期冻结。优先使用当前效果最好的已验证 checkpoint；不能为了实现方便，把明显更弱的模型换成唯一比较基线。Single-LoRA 用于排错最简；若最佳模型是 MoE，则复制其完整状态，精修阶段先固定路由行为，训练既定专家 LoRA，不同时研究新的路由算法。

“共享基座”不意味着训练时更改 adapter 会影响首轮。首轮、精修、old、ref 必须有独立且可核验的 adapter 状态。采样切换 adapter 后，要恢复训练 adapter 与 requires_grad；避免在尚有活动计算图时切换权重。

## 4. P0：基线、数据分割与测量协议

### 4.1 固定真实实验基线

保存当前最佳 checkpoint、配置、代码 revision、完整采样参数、输入文件 hash。先记录：

- B1：现有模型单轮。
- B2：现有模型两轮，原样复现用户已观察到的收益。
- B3/B4：现有模型三轮、四轮，检查退化拐点、累计伪影和内容漂移。
- B2-seed：B2 的多随机种子复测，避免单次采样偶然性。
- Best-of-N：使用现有模型多候选择优，作为搜索基线，单独报告计算成本。

区分“每轮 FM 步数”和“外层 SR 轮数”。初期使用当前最佳采样配置；如果是 25 FM steps，就保留 25，不能为了减轻 RL 采样成本直接降步后与原结果混比。

### 4.2 数据组成

建议第一轮准备如下相互标识的数据：

| 数据用途 | 建议起点 | 要点 |
|---|---:|---|
| 有 HR 的精修训练 | 1,000 个源图起步，后续扩至 5,000–10,000 | 同源多个退化与 crop 归属同一分割 |
| 真实无 HR 的策略训练 | 500 个起步，后续扩至 2,000–5,000 | 来源独立，覆盖目标真实退化 |
| 奖励标注状态 | 300–500 个状态，每状态 4 个候选 | 输出人类偏好、问题类型、置信度 |
| 奖励独立验证 | 至少 100 个源状态 | 与奖励拟合图像分离，含新生成器输出 |
| 算法开发验证 | 150 个有 HR + 150 个真实 LR | 用于调权重与早停 |
| 最终确认 | 独立封存的业务图与公开基准 | 不参与奖励拟合和模型选择 |

按源图、拍摄场景/序列和设备划分，而不是按裁剪 patch 随机拆分。近重复图先去重。RealLR200、RealLQ250 只有未用于调参时才可视作最终独立测试；已经反复用于开发的集合标为开发基准，另外保留未见过的确认集。

覆盖人脸、文字、建筑重复纹理、细线、绿植、平滑背景、夜景、极端模糊。场景可多标签，不用图像总数掩盖少数困难类别。

有 HR 数据必须检查几何对齐、曝光/色彩差异与裁剪一致性；未对齐真实图不能直接把逐像素差异解释为恢复错误。真实无 HR 数据不伪造 HR 标签。

### 4.3 统一执行表示

轨迹缓存同时区分：

- 原始 LR。
- 原始采样 latent：sample_z0。
- 解码后的候选图：raw_sr。
- 实际交付给用户/下一轮的图：executed_sr。
- 下一轮 VAE 重新编码的条件：condition_z_reencoded。

在无局部融合时 raw_sr 与 executed_sr 可相同。若保留 PNG 回灌，训练和验证必须使用一致的 clamp、位深、色彩处理与重新编码流程。先复现现有 PNG 路径，再单独评估取消落盘或使用浮点回灌的收益，不能让它与 RL 改动混在一起。

NFT 使用生成器实际采样的 latent 作为策略样本。不要无声地将它替换为另一张经融合、重编码后的图像 latent。奖励针对实际 executed_sr 计算，下一轮也接收 executed_sr。

P0 产出：baseline_manifest、数据分割表、各场景基线结果、采样速度与显存 profile。

## 5. P1：先建立可信奖励

### 5.1 奖励对象与组成

先输出奖励向量，再输出经校准的固定尺度总分：

\[
\mathbf r=(r_{\mathrm{quality}},r_{\mathrm{faith}},r_{\mathrm{local}},r_{\mathrm{FR}}),
\]

\[
R=w_q\tilde r_{\mathrm{quality}}+w_f\tilde r_{\mathrm{faith}}
+w_l\tilde r_{\mathrm{local}}
+\mathbf1_{\mathrm{paired}}w_h\tilde r_{\mathrm{FR}}-P_{\mathrm{violation}}.
\]

波浪号表示在训练/校准集确定并冻结的尺度变换。真实无 HR 与有 HR 组使用明确记录的奖励配置，不能把缺失 FR 视为低分。初期以“质量、忠实度同等重要”作为校准起点，具体权重由专家排序和验证集决定，不能把来源不同的原始 IQA 数值直接相加。

| 分量 | 实现起点 | 使用限制 |
|---|---|---|
| 视觉质量 | 先选两个在本项目候选上最可靠的 NR-IQA，必要时加入冻结图像评分器 | 不把所有指标都用于训练；保留独立评价器 |
| LR 忠实度 | 原 LR 与 SR 的全局/局部内容一致性，关注结构、身份、重复纹理 | 不能只靠全局语义余弦识别局部幻觉 |
| 局部修复 | 目标区域缺陷变化、区域外不必要改动、边界伪影 | 诊断器报告的目标不是事实，需置信度过滤 |
| 有参考质量 | 对齐 HR 的感知距离、低频/结构与必要重建指标 | 避免单独追求 PSNR 导致过度平滑 |
| 严重违规 | 明显新增/删除内容、可辨文字被改、身份明显漂移 | 不允许高 NR 分数抵消明确违规 |

合成数据的退化一致性按已知退化参数及噪声统计建模；真实数据使用鲁棒低频/结构代理，不能要求简单缩小后的 SR 逐像素等于带噪 LR。LR 不可辨认的字、人脸细节不进行伪精确“真实性判定”，标记不确定并偏向保守修复。

可参考 LR 锚定评价与逐目标归一化的设计，但要验证在本项目数据上的有效性。[LucidNFT v3](https://arxiv.org/html/2603.05947v3)

### 5.2 专家标注与奖励校准

初期不训练大型奖励 VLM。先用现有指标、冻结视觉特征和轻量 pairwise head/校准器构造 reward_v1：

1. 同一状态展示匿名、随机左右顺序的候选，提供原始 LR 与同位置局部放大。
2. 分别记录“更自然”“更忠实”“整体偏好”，允许平局/无法判断。
3. 对文字、人脸等记录严重错误标志；对不确定高频真实性不强迫二选一。
4. 初期每对至少两人独立判断，分歧交第三人；正式确认集建议至少五人。
5. 不先向专家展示模型自述或分数，以减少锚定偏差；图像独立评价后再核对诊断文本。
6. 每次策略出现新型失败，再增补这类样本；训练完 reward_v2 后重新开始受控策略实验。

对于明确偏好 \(y_w\succ y_l\)，可训练：

\[
L_{\mathrm{RM}}=-\log \sigma(f_\omega(x,y_w)-f_\omega(x,y_l)).
\]

平局用软标签或独立平局项；置信度用于样本权重。该损失训练的是奖励模型，不是 SR 策略。

初期可先做 1,000–2,000 个挑选后的候选对。四个候选有六个可能配对，不要求全部标注；优先覆盖分歧、严重伪影与保真/自然度冲突，并保留随机样本评估总体准确率。

### 5.3 奖励验收

建议预登记的工程门槛：

- 对“专家明确偏好”的独立候选对，奖励一致率目标至少 75%，同时报告人际一致率、置信区间和覆盖率；不是把 75% 当普适理论标准。
- 专家确认的严重错误不被系统性选为优胜者；若某一关键类别排序反常，先修奖励。
- 在更强锐化、加饱和、额外纹理、平滑脸部等诊断性样本上检查投机高分。
- 在未用于拟合的生成器/checkpoint 输出上复测，检查奖励能否泛化。
- 奖励输入不含候选 seed、训练 checkpoint 名、候选排名或模型自述。

每个策略 run 固定 reward_version、权重、尺度、阈值。奖励模型更新必须生成新版本，不能在同一 run 内与 SR 模型互相追逐。

P1 产出：reward_v1、专家数据、标注指南、校准报告、固定违规与不确定性处理规则。

## 6. P2：从第二轮验证扩展到多轮状态训练

### 6.1 原始 LR 与当前 SR 的双图条件

当前原生图像条件继续接收 y1。新增原始 LR 分支，输入是对齐到当前坐标系的原始 LR 或其编码特征，必须带来源身份标识。

优先实现单独的可门控残差条件 adapter，初始门控为零，验证启用但零门控时重现原模型。不能把“向 attention 追加全零 token”等同于无影响，因为 softmax 归一化也会改变输出。

若改用两路原生 image-concat token，需给两图不同的图像身份/位置编码，并做专门适配；不默认追加 token 后旧 checkpoint 行为无损。锚点 token 数先从 64–256 的压缩表示试起，另测原分辨率条件的保真与开销；这是待验证的工程选择。

不直接混合原始 LR 像素与 y1 作为唯一输入，以免掩盖“原始证据”和“当前估计”的区别。

### 6.2 第二轮 SFT 预热

数据：\((x,y_1,h)\)。y1 来自冻结 F0，初期每图缓存 1–2 个 seed；同一个实验使用相同首轮缓存，保证可比。

监督目标包含：

- 以 HR latent 为目标的标准 FM。
- 有参考的 latent/重建/感知损失，复用现有有效实现。
- 适度的原始 LR 结构约束。
- 少量高质量/接近完成的输入，训练“无需继续修改”的行为。

高质量输入建议从 10%–20% 起步；既有 F0 的高质量结果，也有适度构造的接近目标样本。避免大量“所有输入都要变成自己”的样本使精修器退化成恒等映射。

建议从 512 crop、继承已验证 LoRA rank 开始；学习率以当前监督 LoRA 的 0.1–0.3 倍做小范围比较。预热先设 1,000–3,000 个优化步上限，依验证集早停，不能把步数当成效果保证。

保存 G_SFT。此时建立同一双图架构下的“纯 SFT”基线，并令 G_ref=G_SFT，G_old=G_SFT，Gφ=G_SFT。

### 6.3 在线候选与改进信号

每个固定状态 \(s=(x,y_1)\)，用 G_old 采样 K=4 个候选，不反传采样链。保留不修改结果 y1 作为比较基线：

\[
\Delta_i=R(x,y_2^i)-R(x,y_1).
\]

y1 是基线，不是 G_old 生成的候选；不能把它伪装成 on-policy 样本混入 NFT 训练。

奖励向量逐目标归一化后再融合；标准差加入由评分噪声估计的下限，避免近乎相同的候选被放大成强偏好。对总分改进 \(\Delta_i\) 保留独立检查，因为组内居首不等于比不修改更好。

得到有界学习权重：

\[
p_i=\frac12+\frac12\operatorname{clip}(A_i/Z,-1,1).
\]

执行以下门控：

- 明确严重违规：进入负反馈，不能获得正向强化。
- 比不修改基线可靠地更差：令 \(p_i\le 0.5\)。
- 差异小于奖励噪声或无法确定：降低偏好权重或跳过该项，保留监督回放。
- 一组全部低质：不强行制造赢家；记录 bad-group 并检查基础能力/奖励。
- 正负样本同时保留，不只反复拟合最高分伪标签。

### 6.4 明确的图像策略更新

采用 DiffusionNFT 的正负隐式速度目标作为图像更新起点；这里给出与本项目 latent/FM 符号一致的形式。该方法以完整生成输出为策略样本，不需要图像 log-prob 或内部采样 step 的 PPO 概率比。[DiffusionNFT v2，式 5](https://arxiv.org/html/2509.16117v2)

对采样 latent z0，重新采样独立训练噪声 ε 与训练时间 τ：

\[
z_\tau=(1-\tau)z_0+\tau\epsilon,\qquad v^*=\epsilon-z_0.
\]

同一输入 \((z_\tau,\tau,s)\) 下：

\[
v^+=v_{\mathrm{old}}+\beta(v_\phi-v_{\mathrm{old}}),\qquad
v^-=v_{\mathrm{old}}-\beta(v_\phi-v_{\mathrm{old}}),
\]

\[
L_{\mathrm{NFT}}=
\mathbb E\left[p\|v^+-v^*\|^2+(1-p)\|v^--v^*\|^2\right].
\]

old 输出、候选、奖励均停止梯度；只更新 vφ 的允许参数。负反馈是上述负分支，不是给普通 MSE 乘负权重。

总损失：

\[
L_G=L_{\mathrm{NFT}}+\lambda_{\mathrm{sup}}L_{\mathrm{paired}}
+\lambda_{\mathrm{ref}}L_{\mathrm{ref}}+\lambda_{\mathrm{pres}}L_{\mathrm{preserve}}.
\]

- \(L_{\mathrm{paired}}\)：独立的有 HR 回放，目标为真实 h，不把所有高奖励生成图当成真实 HR。
- \(L_{\mathrm{ref}}\)：同状态、同噪声时间下的参考速度偏离约束；它是行为锚定代理，不称为精确整图 KL。
- \(L_{\mathrm{preserve}}\)：可靠的原始结构保持/后续局部非编辑区约束。只在有合适可微训练估计时加为损失；外部 VLM/不可微指标只能作为奖励，不能伪装成有梯度损失。

现有 z0 单时间预测解码损失可用于辅助监督；它与完整采样后图像质量不是同一个量，验收始终使用完整推理输出。

### 6.5 最小训练循环

~~~text
固定 F0、G_ref、reward_v1
初始化 G_phi = G_old = G_SFT

每次外层迭代：
    读取 B 个固定状态 (x, y1)
    G_old 无梯度生成每状态 K 个候选
    计算实际输出奖励、违规与相对不修改基线
    构造有界正负权重；保存模型/奖励/数据版本
    顺序读取候选 latent，重加噪计算 NFT
    混入有 HR 的监督回放与参考行为约束
    小步更新 G_phi；每批候选先只使用一遍
    完成本次候选更新后刷新 G_old
    清空或按策略版本隔离旧候选
    定期做固定两轮、单候选输出的独立验证
~~~

初期 old 刷新使用简单、可核验的方案；若选择 EMA，必须把其状态存入 checkpoint，且整个采样/更新批内不变。不要为了扩大有效 batch 让比较组跨不同 old 快照。

建议起点：K=4，每次 8 个状态，可按图串行采样；RL 学习率 5e-6–1e-5 做小范围验证，beta 先 1.0 并参考 0.5/2.0 消融；梯度裁剪 1.0；监督回放比例先 25%–50%。这些值依梯度量级和数据量调整。参考损失先按总梯度贡献检查，避免未经归一化直接移植一个“通用系数”。

以上为 P2 的两轮 smoke 与损失验证入口。两轮下输出强化超过同结构 SFT、严重失败没有增加后，应继续下面的多轮状态训练，不能将只训练第二轮的模型直接多跑两次视为完整多轮方案。若只训练奖励上涨，先回到 P1。

### 6.6 面向第三、第四轮的训练课程

第一阶段 T=2：验证奖励、双图条件、梯度边界和精修基本能力。

第二阶段 T=3：用当前冻结快照生成 y1、y2，训练状态既包含 (x,y1)→y2，也包含 (x,y2)→y3。有 HR 的两类状态都以同一个真实 h 为监督依据；输出强化在各自状态内独立采样候选并比较。

第三阶段 T=4：加入 (x,y3)→y4，持续保留早期轮次训练。每次模型明显更新后刷新 y2/y3 状态，避免后期一直训练旧模型产生的伪影。

实现要求：

- 固定首轮 F0 也可以先训练第 2–4 轮；让第三、第四轮变强不以解冻首轮为前提。
- 共享 Gφ 的训练 batch 按轮次分层抽样，初期可对三类精修状态等额抽样；正式比例由困难状态与遗忘程度决定。
- 同时覆盖欠恢复、局部伪影、过修复、已接近完成的状态；不能只保留前一轮最好的结果。
- 使用当前策略快照生成训练状态，混入少量历史与专家纠正的困难状态；记录分布版本。
- 每个比较组固定原始 LR、当前 SR、当前指令、轮次和预算条件，不能将不同轮次候选混成同一组。
- 不修改基线改为当前 yk，局部增益定义为 R(x,y{k+1})−R(x,yk)。
- 已接近完成的状态训练保持能力；对仍存在可修复缺陷的第三/四轮状态，检查是否获得实际新收益。
- 一次外层采样中所有轮次使用同一 old 快照。训练时合并各轮数据更新共享 φ，而不是在一条尚未采样完的轨迹中途改参数。
- 每次训练同时记录 2、3、4 轮质量，防止让后轮分数上升却牺牲原本有效的第二轮。

P2 的正式产出是经 2→3→4 课程训练的共享精修器，以及逐轮质量曲线。若第二轮持续有效但第三、第四轮仍无增益，先诊断状态覆盖、奖励分辨率与过修复，不直接增加轮数。

## 7. P3：冻结 VLM，验证结构化指令的实际价值

### 7.1 诊断输入与输出

VLM 输入为原始 LR、当前 SR 的对齐图像与必要局部 crop。先支持每图至多两个可信修复区域；全图/局部图的坐标映射必须一致。VLM 不得读取 HR 或训练奖励分数后再“反向编造”诊断。

建议结构：

~~~json
{
  "schema_version": "sr_instruction_v1",
  "state_id": "source_000123_r1_seed42",
  "action": "refine",
  "global_preserve": ["layout", "identity", "color"],
  "regions": [
    {
      "bbox_xyxy_norm": [0.30, 0.18, 0.66, 0.74],
      "issue": "oversmoothing",
      "operation": "restore_texture",
      "strength": "low",
      "confidence": 0.84,
      "preserve": ["identity", "boundary"],
      "evidence": "当前面部纹理过于平滑；原图不支持新增身份细节"
    }
  ]
}
~~~

上述记录仅示范 schema，不代表已有标注。坐标定义为当前 SR 未补边有效区域的 [0,1] 归一化 xyxy；数据记录另存旋转、crop、resize、padding 的变换矩阵。对齐失败时不得执行区域性强修复。

枚举建议：

- action：keep / refine。
- issue：blur / noise / compression / ringing / oversmoothing / color_shift / structure_risk / hallucination_risk。
- operation：deblur / denoise / deartifact / reduce_ringing / restore_texture / correct_color / preserve。
- strength：low / medium / high，但在易幻觉区域初期只允许 low/medium。
- evidence：简短可核验的视觉依据，不要求长篇思维链。

解析失败、区域越界、动作矛盾或置信度低时，退回空指令/全局保守精修。main benchmark 分别固定 2、3、4 轮，并保存每次真正执行精修后的结果；keep/提前停止另外报告。复制 y2 作为 y3/y4 不能计为后轮质量提升，需单独记录实际生成次数与 keep 比例。

### 7.2 指令必须有可执行接口

第一层是已有文本编码器可处理的规范化短 prompt，但不假定 text-only 足以精确控制局部区域。

主执行器逐步加入：

| 字段 | 实际控制路径 |
|---|---|
| 区域 bbox / mask | 映射为当前 latent 坐标下的软区域图，并进入空间条件 adapter |
| operation | 操作 embedding 与规范化短 prompt |
| strength | 有界、可校准的条件强度或残差门控，整轮固定 |
| preserve | 非编辑区保持、身份/结构约束与颜色约束 |
| keep | 显式保持动作，用于停止策略或身份监督 |

strength 不直接对应不存在的“平滑项权重”，也不在本阶段控制 FM 内部每个 step。只有经过监督校准的映射才能作为动作接口。

可以将区域执行写成：

\[
y_{\mathrm{exec}}=y_1+\alpha M\odot(\hat y-y_1),
\]

其中 M 为软 mask、α 为固定于本轮的强度。此式是可选的局部保护执行器，需与空间条件联合评估；它保证区域外像素保持，但可能产生边界接缝或限制全局修复。必须做 mask 羽化、边界检查和全图颜色复测，不能将简单拼接称为完整局部重绘能力。

采用该执行器时，奖励评估 y_exec，而 NFT 的生成动作样本仍是原始 \(\hat y\) 对应的 sample_z0。保存 raw/executed 两种图像，不能把融合结果冒充原策略直接生成的样本。

### 7.3 指令跟随预热与因果对照

冻结 H、F0、R；先训练 G 的空间/操作 adapter 与精修 LoRA，使“同一输入，不同指令”产生预期的局部变化：

- 使用有 HR 数据构造局部模糊、局部噪声、振铃、过平滑等残余退化。
- 训练样本明确提供缺陷区域、允许操作和保护区域。
- 混入真实首轮结果及专家指令，减少构造缺陷与真实伪影的差距。
- 定向任务只监督需要修复的区域与可靠的保持区域；不能对互相矛盾的指令一律要求同一输出。
- 提示词只是辅助条件时，也要承认实际收益可能来自结构化控制 adapter。

必须设置相同结构/训练量的对照：

- C0：全局通用指令，无诊断。
- C1：正确状态对应的冻结 VLM 指令。
- C2：按场景匹配但错误配对的合法指令，用于离线因果检验。
- C3：专家修正指令，用于估计诊断器的改进空间。
- C4：C1 的 text-only 与 text+空间控制消融。

C1 优于 C0、C2，且在目标区域改善、保护区域损伤不增加，才说明指令被有效利用。若 C3 有效但 C1 无效，优先改诊断器；若 C3 也无效，先改执行器，暂不训练文本 RL。

每个状态的诊断缓存 key 至少包括：原图 hash、当前 SR hash、轮次、VLM 版本、诊断 prompt/schema 版本。不能仅按原图文件名复用。编码后的文本缓存继续用实际规范化 prompt hash 与 encoder signature。

### 7.4 指令条件下的图像强化

完成跟随预热后，保存新的指令条件 G_ref。对同一 (x,y1,d) 生成 K=4 个候选，用 P2 的输出级目标更新 G。H 仍冻结。

状态变化时重新诊断。此阶段不把奖励回传给 H，也不把 H 自己的评分作为唯一奖励。候选与条件从 y1、y2、y3 分层采集；前述固定 (x,y1,d) 的训练公式逐状态复用。接受该阶段后，形成多轮推荐系统：

原始 LR → 冻结首轮 → [按当前 SR 重新诊断 → 指令条件精修] 重复执行 → 第 T 轮 SR。

P3 产出：instruction_v1 schema、双图诊断器、可执行局部控制、指令跟随数据与消融报告、固定 H 的输出强化 checkpoint。

## 8. P4-A：仅在指令有用时，学习指令选择策略

### 8.1 先训练有限候选选择器

为同一状态由冻结 H 产生 L=4 个合法提案，例如保守去噪、轻量去振铃、纹理恢复、保持。候选数量不强行填满；无可信操作时允许只有 keep。

用冻结 G 对每个指令续采样 M=2 个结果，采用共享图像噪声集合，估计：

\[
Q_d(s,d)=\frac1M\sum_j R(x,G_{\mathrm{old}}(s,d;\epsilon_j)).
\]

训练一个轻量分类/排序策略 \(\pi_\psi(a|s,\mathcal D)\)，其中动作 a 是候选指令索引。候选顺序随机化，避免学习位置偏好。预热可用 Q 排名监督；该预热明确是监督学习。

再使用在线采样的指令及其执行回报做 bandit 策略更新。该策略的分类概率可精确计算，因此能够使用标准策略梯度或 PPO 式裁剪更新。[PPO 原论文](https://arxiv.org/abs/1707.06347)

关键记录：采样动作、old log-prob、候选集合、动作合法性 mask、实际执行回报。更新比率使用实际采样时的分布；不能改变温度、合法动作 mask 后仍复用旧概率。

诊断器 H、图像执行器 G、奖励 R 均冻结，只更新选择器 ψ。学习信号来自执行后的 SR，不能只奖励指令长度、术语数量或诊断自信程度。

### 8.2 再决定是否直接训练 VLM 指令生成

如果有限候选覆盖率限制了收益，再用执行结果排序构造指令偏好，先 SFT/离线偏好适配 H，再开展在线文本策略训练。指令序列必须包含区域/操作的结构化表达，并使用真实生成分布的 token log-prob；不把图像生成器的 seed 概率当作图像策略概率。

DPO 可作为指令偏好预热方案，但应按离线偏好优化报告，不能把它自动等同于在线多轮 RL。[DPO 原论文](https://arxiv.org/abs/2305.18290)

初期不同时更新 H 和 G。每个窗口固定一个模型训练另一个，更新后重算指令效果，并限制训练窗口内旧经验的复用。

进入 P4-A 的条件：C1/C3 的指令价值已被验证，同时“可选指令之间的执行质量差”显著大于续采样噪声。否则训练选择器只会学习随机排名。

## 9. P4-B：面向第三、第四轮的终局信用分配

P2/P3 已经必须覆盖多轮状态；P4-B 在此基础上学习各次修改对后续恢复的贡献。P4-A 指令学习仍可独立选择。默认先保持首轮冻结，优化共享精修器的多轮行为；首轮解冻作为进一步消融。

### 9.1 当前修改如何影响后续轮次

固定当前状态 s_k=(x,yk,dk,k,T)，其中 k 是已经执行的轮数，T 是本次目标预算。用 old 精修器生成若干下一轮候选 y{k+1}^i，各自沿同一冻结后续系统续采样到 T：

\[
Q_k(s_k,y_{k+1}^i)=
\frac1M\sum_{j=1}^{M}
R\!\left(x,y_T^{(i,j)}\right).
\]

对第二轮候选，可以用第三/第四轮结果评价其后续可恢复性；对第三轮候选，可以用第四轮结果评价；最后一轮直接使用其输出奖励。每个后续状态都重新诊断，使用同一冻结 H。若指令策略随机，固定其快照并计入续采样随机性。

将同状态的 Q 差异转成 NFT 权重，用当前轮真实输出样本更新 Gφ。候选、Q 和整个续采样过程停止梯度。共享精修器在一次更新后会影响多个轮次，因此混合各轮状态训练、固定 old 采样并及时刷新尤其重要。

### 9.2 终局质量与逐轮收益同时检查

只优化第四轮最终分数，可能使第二轮变差；只要求每次即时 IQA 上涨，又可能阻止有益的中间调整。建议从以下受约束目标开始消融：

\[
J=\mathbb E_{T\sim p(T)}
\left[
R(x,y_T)
-\lambda_d\sum_{k=2}^{T}
\max\!\left(0,R(x,y_{k-1})-R(x,y_k)-\varepsilon\right)
-\lambda_v\sum_{k=1}^{T}V(x,y_k)
\right],
\quad T\in\{2,3,4\}.
\]

R 使用固定校准尺度；ε 表示评分噪声/允许的小幅波动，V 表示可信的内容违规。p(T) 初期可均匀抽样，随后根据后轮收益与早轮遗忘调整；每种预算始终单独报告。

实现时用上述终局质量和未来惩罚形成 Q 的后续回报；不要重复加计两套不同定义的终局奖励。当前轮的轻微暂时观感下降使用软惩罚，不机械沿用仅即时奖励阶段“任何下降都不得正向更新”的规则；明确内容违规始终受到约束。

逐轮差分奖励之和在不折扣、不截断时会望远镜相消为终局与初始分数之差。因此，仅把 R 换成 ΔR 不是多轮信用分配已经解决的证据。必须测真实后续收益、状态分布与 Q 排序质量。

### 9.3 控制分支成本与更新

不展开 K 的 T 次方全树。每批从已采样轨迹选择一个轮次状态，生成 K 个当前动作，每个动作做 M 条到终局的完整续采样。候选之间使用共享的后续随机数集合降低比较噪声。

若前缀已经缓存，从已执行 k 轮的状态出发，新增 SR 调用数为：

\[
K+KM(T-k-1).
\]

例如 T=4、k=1、K=4、M=2，当前生成第二轮需 4 次，续采样第三和第四轮需 16 次，共 20 次；不是展开全部 4^3 个分支。其他 batch 分别选择 k=2、3，以覆盖各轮信用。

同一比较组固定状态、轮次、目标预算和 old 策略；Q 使用原始固定尺度，不先对每条分支单独归一化，也不取分支最大值。提高 M 复查一部分状态的排序稳定性后，再决定是否加大训练。

仅当首轮已成为后续恢复瓶颈，才解冻其 adapter θ，沿同一终局续采样方式估计首轮价值；与共享精修器交替训练，避免一开始同时更改整个系统。

此方案是输出级近似策略迭代，不是跨完整生成链的精确反传，也不保证每张图逐轮单调提高。验收重点是第三、第四轮的实际新增收益、早期轮次质量保持，以及固定 3/4 轮预算下超过 P3。

## 10. 统一实验矩阵与验收

### 10.1 最小实验矩阵

| ID | 图像模型训练 | 指令 | 奖励/条件 | 主要回答 |
|---|---|---|---|---|
| E0 | 无新增训练 | 原有方式 | 当前设置 | 1–4 轮原始质量曲线 |
| E1 | 第二轮 SFT | 无诊断指令 | 双图条件 | 仅分布适配能提升多少 |
| E2 | E1 + 图像 NFT | 无诊断指令 | reward_v1 | 奖励训练是否超过 SFT |
| E3 | 匹配训练量的指令 SFT | 通用合法指令 | 与 E4 相同空间结构 | 排除新增参数/训练量影响 |
| E4 | 指令 SFT | 正确冻结 VLM 指令 | 原 LR 与局部控制 | 指令本身是否有效 |
| E4-shuffle | 与 E4 相同 | 合法但错误配对 | 其余相同 | 是否真正使用诊断 |
| E4-oracle | 与 E4 相同 | 专家修正指令 | 其余相同 | 诊断器还是执行器受限 |
| E5 | E4 + 图像 NFT | 冻结 VLM | 固定同版奖励 | 完整第一版融合系统 |
| E6 | 固定 E5 图像模型 | 学习指令选择 | 最终 SR 回报 | 文本/选择策略强化收益 |
| E7 | 多轮共享精修；可选首轮交替训练 | 固定指令系统 | 分轮终局 Q | 第三、第四轮与多轮协同收益 |

E2 与 E1、E5 与 E4 应匹配总优化步数/图像曝光量，设置继续 SFT 的对照；不能让强化模型单纯多训练一倍。新增空间 adapter 的效果用相同结构的空/通用指令控制。

E1/E2 先做两轮最小对照，再增加“仅第二轮训练→直接跑四轮”与“2→3→4 轮状态课程训练”的关键消融，用来区分单纯增加调用与真正学习后轮恢复。E4/E5/E7 均覆盖第 2、3、4 轮。

主要比较固定 2、3、4 轮、无候选择优的真实输出，记录每个前缀。另设停止/择优模式，明确 N、选择器、实际 SR/VLM 调用次数；不把搜索收益或提前退出写成后轮生成能力提升。

必须分开报告四类结果：

1. 新模型 y3/y4 是否超过旧模型在相同轮数的结果：证明同预算改善。
2. 新模型 y3/y4 是否超过旧模型最佳两轮结果：证明后轮具有实用价值。
3. 新模型自己的 y3 是否超过自己的 y2、y4 是否超过 y3：证明新增轮次仍在发挥作用。
4. 新模型自己的 y2 是否维持或提高：防止通过故意弱化早轮制造虚假的后轮增益。

新增统计包括 Δ3=R(y3)−R(y2)、Δ4=R(y4)−R(y3)，对应的人工相邻轮偏好率、有效改善比例、退化比例、keep 比例、严重错误与各场景细分。R 只是诊断统计，最终仍以独立评价和盲评验证。

### 10.2 评价项

- 有 HR：对齐后的 PSNR/SSIM、感知距离和结构/颜色误差，固定通道、crop border、resize 协议。
- 无 HR：训练外保留的 NR-IQA、LR 内容一致性、文字/人脸/重复结构局部检查。
- 人工：匿名并排、随机左右、允许平局；记录自然度、忠实度和整体偏好。
- 保持性：目标区域改善、非目标区域改动、mask 边界、色彩漂移。
- 稳定性：多 seed 的平均质量、方差、严重失败比例与第 2/3/4 轮增益曲线。
- 资源：每图完整 SR 调用、FM 网络评估数、VLM 调用与 token、峰值显存、GPU 时间、端到端延迟。
- 指令：有效 JSON 比例、区域准确性、无操作比例、执行后实际收益，不只看文本正确率。

建议开发阶段主门槛：整体偏好胜率目标至少 55%，并使用按源图聚类的 bootstrap 给出 95% 区间；强结论需区间下界超过 50%。多个 crop、seed、评审者不能当成完全独立图像样本。对关键失败率同时报告差值与区间。

保真非劣阈值在 P0 固定：根据 baseline 多 seed 波动、对齐误差及业务容忍度设定。初期可以将 PSNR 平均下降 0.2 dB、LPIPS 绝对恶化 0.005 作为讨论起点，但不得跨数据协议机械照搬，也不能替代严重内容错误检查。

若样本量不足以得到窄区间，结论写“证据不足，需增加确认样本”，不能把未显著变差宣称为无损。

### 10.3 失败后的动作

| 观察 | 优先排查 | 下一步 |
|---|---|---|
| 奖励上升，盲评/保真下降 | 奖励投机或尺度失衡 | 暂停策略训练，补充困难偏好与忠实度约束 |
| E1 好，E2 无额外收益 | 奖励分辨率、更新过强、候选缺乏差异 | 检查组内分差与梯度，保留 E1 |
| 正确与打乱指令结果近似 | 指令被忽略或条件接口失效 | 先做跟随预热与局部执行检查 |
| 专家指令有效，VLM 指令无效 | 诊断错误/定位错误 | 改 H 或指令数据 |
| 专家指令也无效 | 执行器能力不足 | 改空间条件和训练目标 |
| Q1 排序随 seed 大幅变化 | 续采样方差太高 | 增加 M/共享噪声/减小策略更新 |
| 简单图越修越差 | 过度修复 | 增加高质量样本与 keep 校准 |
| 高分只出现在 best-of-N | 搜索贡献大于学习贡献 | 单独报告搜索；检查部署单样本收益 |

前七项优先形成最小质量验证闭环。第九项以后在 E2 和奖励验收完成后推进；第一轮可以提前制作少量专家指令测执行器潜力，但不应抢占主线全部资源。

对真实参数更新和数据分组必须有针对性检查：

- NFT 在 θ=old、p=0.5 时偏好梯度为零；p=1 与 p=0 的初始偏好梯度方向相反。
- 首轮、VAE、文本编码器、old、ref 的不应训练参数梯度为空，更新前后 checksum 不变。
- 输入组固定时奖励置换会改变训练方向；更换 reward_version 不会复用旧优势。
- 双图零门控严格复现基线；普通双图启用与精修 adapter 切换可重复。
- bbox 在 resize、crop、padding 后位置正确；执行后的 mask 外像素符合保护约定。
- NFT 的样本 latent 与实际生成器输出一致；不能误用融合后 latent。
- 第二轮比较不跨 y1/d；首轮 Q 不取分支最大值。
- 中断恢复能够还原 optimizer、RNG、old、ref、adapter、buffer 版本，避免重复或漏计采样。

这些检查验证真实易错边界；不为文档本身编写形式化测试。

## 13. 计算预算与阶段安排

定义一次完整 SR 调用成本为 C_SR，冻结 VLM 诊断成本为 C_H。C_SR 包含当前 FM 步数、VAE 和双图条件开销。先用 100 张代表图测量，再乘候选量估算，不能直接套用其他论文 GPU 时长。

| 阶段 | 每个 LR/状态的主要采样调用 |
|---|---|
| P2，首轮未缓存 | 1 次首轮 + K 次精修；K=4 时共 5 次 SR |
| P2，首轮已缓存 | K 次精修 |
| P3 | 在上述成本上，每个新 y1 状态约 1 次 H 诊断 |
| P4-A，L=4、M=2 | 缓存 y1 后 8 次精修；指令提案的 VLM 次数按实际生成方式计 |
| P4-B，两轮调试、K1=4、M=2 | 4 次首轮 + 8 次精修 + 各状态 H 诊断 |
| P4-B，四轮、缓存 y1 后在第二轮分支，K=4、M=2 | 4 次第二轮 + 16 次后续精修，共 20 次；各新状态重新诊断 |

若每次 SR 为 25 FM steps，则上表两轮调试为 300 次主干网络评估；四轮、缓存 y1 后的第二轮分支评估为 500 次，尚不含前缀、NFT/监督更新、VAE、奖励和 VLM。主线部署可为一条 2/3/4 轮轨迹，不携带训练时的 K×M 搜索。测量继续到第三、第四轮的边际质量和边际延迟，不能只报终局总分。

多候选可串行生成，采样无计算图，优先降低显存而非把 K 全塞入一个 batch。训练 old/ref/当前模型共用冻结基座时，只是节约权重副本，仍要保留各自 adapter 状态并计入额外前向。VLM、IQA 与 SR 可分时加载或使用本地独立进程，依据实际设备调度。

| 阶段 | 交付物 | 进入下一阶段条件 |
|---|---|---|
| P0 | 可复现 B1/B2/B3/B4、数据分割、profile | 两轮优势与第三、第四轮退化被确认 |
| P1 | reward_v1、专家标注、校准报告 | 奖励排序可信，关键错误不被奖励 |
| P2 | 经 2→3→4 课程训练的 G_SFT、G_RL、逐轮报告 | 强化超过 SFT；检查后轮有效收益与早轮保持 |
| P3 | 指令 schema、执行器、逐轮重新诊断的融合模型 | 正确指令有因果收益并改善后轮表现 |
| P4-A | 指令选择策略 | 超过固定指令策略，且计入额外成本 |
| P4-B | 多轮协同模型 | 固定 3/4 轮超过 P3，后轮有实际增益，Q 排序可用 |
| P5 | 按预算需要的学生模型 | 压缩后仍保留可接受质量收益 |

每阶段交付后保留一个可回退的最佳 checkpoint。P4 任一分支失败，不影响已经通过验收的 P2/P3 成果。

## 14. P5：质量成立后再安排压缩

先明确交付预算：单轮 FM 几步、外层 SR 几轮、是否保留 VLM、目标硬件与延迟。上传计划中的“diffusion 一步”与“1–4 步蒸馏”、外层多轮是否保留需要分别定义，不能混成一个“步数”。

可选路径：

1. 保留已验证有效的多轮机制，压缩每轮生成器，减少单轮 FM 步数。
2. 用通过质量门槛的多轮系统生成训练目标，按部署预算蒸馏为更少轮次的学生。
3. 用结构化指令/执行结果训练轻量诊断器或选择器，替代大 VLM。
4. 将“无需修改”的决策交给轻量停止策略，按平均调用量重新评价。

教师输出是带偏差的伪目标，必须通过奖励与保真筛选，并混入真实 HR 监督。蒸馏到更少轮后，多轮质量优势可能下降；量化和端侧实时性必须实测，不预先承诺无损或毫秒级。

## 15. 第一批建议实际启动的工作

执行顺序：

1. 固定当前最佳首轮模型，选取 200 张开发诊断图，复现一/二/三/四轮与多 seed，并比较相邻轮次。
2. 从 y1、y2、y3 状态分别采集少量 K=4 下一轮候选，检查奖励分辨率和人工排序。
3. 建立源图级数据拆分，准备约 1,000 有 HR / 500 真实 LR 的初期训练池。
4. 实现并验证双图条件零门控与状态缓存；建立 G_SFT 基线。
5. 完成 reward_v1 校准与输出 NFT 的梯度/冻结检查。
6. 跑 E1/E2 的两轮调试后，进入 2→3→4 轮状态课程，比较仅第二轮训练的模型与多轮训练模型的完整质量曲线。
7. 在各轮的小规模专家指令样本上检查“指令可执行性”；成立后开展逐轮重新诊断的 P3。
8. 根据指令效果和后续信用分配的瓶颈选择 P4-A 或 P4-B；首轮解冻另行消融，不把它当作后轮提升的必要前提。

第一批交付应是一份可以回答“为什么 SR 变好了”的实验报告：更好的奖励、精修分布适配、结构化指令、输出强化各贡献多少，并列出尚未解决的失败类型。
